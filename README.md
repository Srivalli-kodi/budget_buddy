# budget_buddy
Budget Buddy is a personal finance management app designed to help users track income, expenses, and savings goals with ease. Whether you're managing your daily expenses or planning your financial future, Budget Buddy provides simple tools and visualizations to stay on top of your budget.

🚀 Features

- ✅ Add and delete expense entries
- 📅 Filter expenses by:  
  - Last 3 Days  
  - This Week  
  - This Month
- 📊 Visualize expenses using interactive charts (Recharts)
- 💾 Data persistence using browser localStorage
- 🧠 Built with React Context for global state management


TECHNOLOGIES:
  1.MONGO DB
  2.HTML,CSS
  3.Node.js,chart.js
